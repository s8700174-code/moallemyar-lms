Persian teacher and parent learning portal with H5P integration.

== Description ==
A pilot WordPress plugin for role-based learning, course progression and reporting.
See the repository README for installation, SMS configuration, privacy and validation limits.
H5P must be installed separately. No learner data or credentials are included.

== Installation ==
Copy this directory to wp-content/plugins/moallemyar and activate it after installing H5P.
Configure courses, membership and the SMS provider before real-world use.
